# Bài tập Machine Learning - Perceptron & Gradient Descent

Repository này chứa mã nguồn giải bài tập về thuật toán Gradient Descent và Perceptron. 

## Cấu trúc thư mục
- bai_3_26.py: Thuật toán Gradient Descent tìm cực tiểu hàm số.
- bai_3_27.py: Dự báo nhãn bằng Perceptron.
- bai_3_28.py: Cập nhật trọng số của Perceptron.
- bai_3_29.py: Xây dựng Class `Perceptron` theo hướng đối tượng (OOP).
- bai_3_30.py: Áp dụng Class Perceptron để phân lớp nhị phân tập dữ liệu Breast Cancer.
- requirements.txt: Các thư viện cần thiết.
